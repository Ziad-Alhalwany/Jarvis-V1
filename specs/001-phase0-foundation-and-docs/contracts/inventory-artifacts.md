### Rules

- **Heading text is fixed** exactly as above. Only values change.
- **Row order** is fixed: domains by `number`, then `specs`; features by number; roles by card
  path, case-insensitive, with ordinal tiebreak for stability.
- **Numeric columns right-aligned** with the colon-dash form shown; no thousands separators.
- **No absolute paths.** The workspace root is never printed; a relative path is sufficient.
- **ASCII only.** Hyphens, not en-dashes or em-dashes; no smart quotes.
- **Fixed widths derived from data**, so a two-run golden comparison is byte-identical. No
  wrapping, no truncation; long paths lengthen the row.
- **`Last verified` is a date**, rewritten only when another line in the file changed.
- Trailing newline at end of file. Single trailing newline, never two.

### Level column

Derived from the path only, because Phase 0 does not parse card bodies:

| Path pattern | Level |
|---|---|
| `jarvis_prime` | 1 |
| `30_infrastructure/executive_command/*` | 2 |
| `00_c_suite_leadership/*` | 2 |
| `00_pillar_lead` | 2 |
| `*/manager` | 3 |
| anything under `workers/` | 4 |

### Scope column

Derived from the path: `global` for `00_global_system` and `30_infrastructure`, otherwise the pod
directory name.

## 2. `ARCHITECTURE.md` telemetry region

Exactly this block, replacing everything between the markers:

```markdown
<!-- AUTO-STATS-START -->

- **Accountable owner:** `documentation_guardian`
  (see `30_infrastructure/executive_command/documentation_guardian/AGENT.md`)
- **Generated by:** `00_global_system/scripts/doc_guardian.py`
- **Last verified:** `YYYY-MM-DD`
- **Active structural directories:** `0`
- **Placeholder (planned) directories:** `0`
- **Live role cards (`AGENT.md`):** `0`
- **Quarantined role cards:** `0`
- **Skill bundles (`SKILL.md`):** `0`
- **Specification features:** `8`

<!-- AUTO-STATS-END -->
```

### Rules

- **Line order is fixed** as above. The owner line must be first, because SC-014 is tested by
  locating the owner of each region.
- **Backticked values only.** Table rendering must not be required to read the numbers.
- **No clock time.** `Last verified` is a date, and it is only rewritten when another value
  changed. This is the fix for the pre-existing non-deterministic `18:00:00` line (R3).
- **Numbers reflect the same snapshot** as `DIRECTORY.md`, taken in the same run.
- Marker lines are preserved byte-for-byte by the generator; it replaces only the interior.
- Prose immediately outside the markers is untouched (SC-005).

## 3. Why these figures and no others

| Figure | Justification |
|---|---|
| Active directories | Answers "how big is the structure" and is stable across content edits (R4) |
| Placeholder directories | Proves SC-011 without claiming work is done |
| Live role cards | The headcount the Commander actually commands today |
| Quarantined role cards | Prevents the archived seeds from silently inflating headcount (FR-036) |
| Skill bundles | Required by FR-023; currently zero, and zero must be printed honestly |
| Specification features | Proves the eight phase slots are reserved, not completed |

Deliberately omitted: file counts, line counts, token estimates, and any figure that changes on
every commit. Each omitted figure would make idempotency fragile without answering a governance
question.

## 4. Failure behavior

| Situation | Behavior |
|---|---|
| Region markers malformed | Exit 2, no writes anywhere, including `DIRECTORY.md` |
| Manifest missing quarantine file | Quarantined count is `0` with a warning on stderr, not an error, because the archive is populated in the same phase |
| Owner card missing | Drift kind `ownership_gap`, exit 1 |
| Rendered content identical | No write at all; mtime preserved |
| Interrupted between the two artifacts | Each is written atomically and independently; the next run converges. Both artifacts are derived, so no state is lost |
